## Findings

**[P1] Input focus indicator too weak.** `inputClass` (`packages/ui/src/classes.ts`) uses `outline-none
focus:border-brand`: the only focus cue is a 1px border changing colour. IBA brand on dark surface = **2.87:1**
(< 3:1, WCAG 1.4.11 / 2.4.7). Fix: keep the border change and add a ring, e.g. `focus-visible:ring-2
focus-visible:ring-brand/40`, or drop `outline-none` and style `outline`. → `/impeccable harden`

**[P1] `brand-ink` is always white.** Any light tenant colour breaks text on `bg-brand` (buttons, cover art,
generated logo). Amber `#F59E0B` with white text = **2.15:1**. IBA (6.18) and demo (5.47) pass today. Fix: the layout
already validates the hex, so it can also compute `--brand-ink` (#fff or #111) from luminance. Alternatively,
reject tenant colours under 4.5:1 in the Tenants collection. → `/impeccable harden`

**[P2] Input borders 1.29:1 (light) / 1.25:1 (dark).** WCAG 1.4.11 asks 3:1 for the boundary that identifies a
control. `LeadForm` relies on placeholders plus `sr-only` labels, so sighted users find the field by its border
alone. Fix: a stronger border token for inputs (`--line-strong`), not the divider colour. → `/impeccable harden`

**[P2] ThemeToggle touch target 40×40px** (`size-10`) < 44px. Fix: `size-11`. → `/impeccable adapt`

**[P2] `CoverArt` images load eagerly.** Course rows render many card images with no `loading="lazy"` or
`decoding="async"`. Fix: `loading` prop, `lazy` for `card`, `eager` for `hero`. → `/impeccable optimize`

**[P3] `NoticeBar` uses `role="status"`.** That's a live region; a static banner should be a plain `<aside>`/region
with a label. → `/impeccable harden`

**[P3] Card hover lift ignores reduced motion.** `CourseCard` `hover:-translate-y-1` → add
`motion-safe:`. → `/impeccable animate`

**[P3] `::selection` text colour hard-coded `#111`** in `styles.css`. Fine on amber; use a token if accent becomes
tenant-dark. → `/impeccable polish`

## Working well
- One token system, CSS variables mapped through `@theme inline`; tenant colours injected and validated server-side.
- Dark mode via `data-theme`, set before paint (no flash); toggle persists and swaps its `aria-label`.
- Marquee gated by `prefers-reduced-motion`; every grid starts at one column; no overflow at 375px on 5 pages × 2 tenants.
- Text contrast passes AA in both themes (muted on bg 5.59 light / 7.52 dark).
- Self-hosted fonts, no external runtime requests.

## Recommended order
1. [P1] `/impeccable harden` — focus ring, auto `brand-ink`, input border token, NoticeBar role
2. [P2] `/impeccable adapt` — 44px toggle
3. [P2] `/impeccable optimize` — lazy images
4. `/impeccable polish`

These change pixels, so they belong in a follow-up PR, not E-012.

## Resolution (`feature/ui-a11y-hardening`)

| Finding | Fix |
| --- | --- |
| P1 input focus | `inputClass`: `focus:border-focus focus:ring-1 focus:ring-focus` = 2px edge in `--focus`. Buttons and ThemeToggle get `focusRing` |
| P1 `brand-ink` always white | `tenantPalette()` in `@edvora/ui/color` derives `--brand-ink`, `--accent-ink`, `--focus` (light + dark) per tenant; layout injects it. Unit-tested for blue, teal, amber, pale yellow, black |
| P2 input borders 1.3:1 | New `--line-strong` (`#888884` / `#676b72`, ≥3:1 on all surfaces) on inputs and instalment chips |
| P2 toggle 40px | `size-11` (44px) |
| P2 eager images | `CoverArt`: `loading="lazy"` for cards, `eager` for hero, `decoding="async"` |
| P3 NoticeBar live region | `<aside aria-label>` |
| P3 hover lift | `motion-safe:` on CourseCard |
| P3 selection colour | `color: var(--accent-ink)` |
| Extra (found while fixing) | Instalment chips hid the radio with `sr-only`, so keyboard focus was invisible. They now show a `has-focus-visible` outline |

IBA and demo keep white button text and the same brand/accent; the visible changes are darker input/chip borders, a
2px focus edge, a slightly lighter focus colour in dark mode, and a 4px larger theme toggle.
