3. **Decisions made**
   - New key `finance.view` instead of reusing `orders.view`: the read-only `reporting` template holds
     `orders.view`, but the new tabs also write contact notes. Granted to existing finance/admin roles by migration.
   - Refund amount limit = paid − (requested + approved + refunded); one open request per order, so two people
     cannot each ask for the full amount.
   - The requester can never approve or mark refunded; marking refunded also needs `refunds.approve`. Rejecting is
     allowed to the requester if they hold the key (safe direction, as ADR 017).
   - Full refund → order `refunded`, enrolment `cancelled`, cohort seat released (mirror of `onFirstPayment`).
     Partial refund changes only the money record.
   - Imported (WordPress) orders cannot be refunded in Edvora.
   - Export: GET route (not a server action) so the browser downloads the file; audit row written before the file
     is sent, export refused if it cannot be logged; 404 for anyone without `finance.export`.
   - KPI «collected this month» is gross (paid instalments since the 1st of the Jalali month); refunds shown apart.
