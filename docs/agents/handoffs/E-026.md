3. **Decisions made**
   - Counted attempt = **best**; multiple choice **all-or-nothing** (proportional is a per-quiz option); no negative
     marking; no retake after passing — all configurable defaults listed as client questions.
   - Correct answers are never in the page before submit; after submit only if the quiz's review setting allows.
   - Short answers: normalise (Latin digits, ي/ك→ی/ک, no tatweel/diacritics, ZWNJ→space, collapsed whitespace,
     case-insensitive) then exact match.
   - Time limit: server clock is the authority; on time-out the saved answers are auto-submitted and the attempt counts.
   - Drip unlock is computed on read, never stored; an opened lesson is never re-locked; day starts 00:00 Asia/Tehran;
     no cohort → "days after cohort start" counts from enrollment; free-preview lessons ignore drip.
   - Students write attempts/submissions only through Zod-validated server actions; the REST API refuses those
     creates from students.
   - Submission files: random names, magic-byte type check, outside any public path, served only by an authenticated
     route that checks tenant + owner or `submissions.grade` in scope; 404 otherwise (ADR 009).
   - Certificate *creation* is refused only for an open required quiz/assignment — progress/defense are not
     enforced at creation so imported historic certificates keep working.
   - A locked lesson URL returns 200 with the lock message and no content (not 403) — simpler for the page; content is
     never rendered or exposed through the API.
   - An assignment may optionally be attached to a lesson; if required, it gates that lesson.
