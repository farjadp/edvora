# E-035 — One console for `/admin` and `/staff` (template reverse-engineered, Edvora palette) + Persian admin by default

**Agents:** ui-designer → tech-lead → qa (orchestrated) · **Date:** 2026-11-07 · **Branch:** feature/admin-console-e035
(based on `develop` + `feature/gamification-seal` / PR #21)

1. **Task:** Farjad sent the Fleetyu inventory template and asked for its modules and layout, rebuilt for our needs,
   in our own colours. Scope chosen: one shared shell and design system. `/staff` gets the full template layout, and
   `/admin` gets as much of it as Payload allows. The parent session added one more requirement: `/admin` defaults to
   Persian/RTL whatever the browser language, with English selectable in Account.

2. **Output**
   - **Design system:**
     - `packages/ui/src/console-tokens.css`
     - `packages/ui/src/console/*` (`@edvora/ui/console`): shell, sidebar, header, ⌘K palette, KPI card, sparkline,
       bar and donut charts (SVG, no chart library), tables, pager, empty states.
     - `docs/design/system.md` (console section).
   - **`/staff`:** desks in `apps/web/src/components/staff/desks/*` for overview, finance, leads, students, teaching,
     content and support. Each desk has KPIs with 30-day deltas, charts, an inbox and tables. The nav is filtered by
     permissions (`lib/consoleNav.ts`), and the data comes from `lib/consoleData.ts`.
   - **`/admin`:**
     - `components/admin/{AdminNav,HeaderTools,DashboardHome,ListKpis}.tsx`
     - Grouped sidebar, ⌘K palette and a KPI dashboard.
     - KPI strips above the Orders, Leads, Enrollments and Submissions lists.
     - Theme in `custom.scss`.
   - **Numbers rules:**
     - `@edvora/core/console` and `@edvora/core/staff-goals` compare the last 30 Tehran calendar days with the 30
       before.
     - Settled sales means instalments paid, counted by `paidAt`.
     - Scope is one academy, the user's staff academies, or the platform (platform admin only).
   - **Language:** `apps/web/src/proxy.ts` and `lib/adminLanguage.ts` set `payload-lng=fa` on `/admin` when the cookie
     is missing or unsupported. An English choice made in Account is kept. Persian labels exist for every nav group and
     collection, checked by `collections/labels.test.ts`. Recorded in `docs/adr/015-admin-language-default.md`.
   - **Migration:** `20261107_044010_e035_merge_snapshot` is a no-op that carries the merged E-028 + E-031 schema
     snapshot.
   - **Tests:**
     - First Vitest suite in `apps/web` (nav filtering, labels, spark shape).
     - e2e: `admin-language.spec.ts` and the `console-qa*.spec.ts` set (role matrix, access, visual/axe, keyboard,
       editor, data).
   - **Screenshots:** `docs/design/e035/before-*`, `after-*` and `qa-*` (light/dark, 1440/375, demo + iba). Capture
     script: `docs/design/e035/capture.mjs`.

3. **Decisions made**
   - **Palette:**
     - Turquoise `#40B5AD` is the accent, with petrol text on it. White on turquoise is about 2.5:1 and fails.
     - Petrol `#123C55` is the light-mode ink and the dark-mode base.
     - Warm white `#F7F3E8` is the light-mode background.
     - Gold `#C9A45C` is reserved for milestones and is currently unused.
     - Iranian blue `#1C39BB` is not used.
     - The academy's own colour appears only on the sidebar logo chip.
   - **Template modules mapped to Edvora:** inventory/fleet became courses, enrolments and orders. Alerts became the
     finance and leads inboxes. Activity became the audit log. Nothing logistics-specific was carried over.
   - **Access unchanged:** the nav and KPIs only *read* existing permissions. `payloadAllows()` treats
     `{permission, where}` as allowed-with-filter, and every console query adds an explicit tenant filter.
   - **No external requests:** Gravatar was removed from the admin header (`admin.avatar: 'default'`). Fonts are
     self-hosted, and charts are hand-written SVG.
   - **E-028 files reworked:** be aware when reviewing PR #21.
     - `components/staff/FinanceDesk.tsx` and `LeadsDesk.tsx` were replaced by `desks/*`.
     - `staff/(desk)/[desk]/page.tsx`
     - The Enrollments, Leads and Submissions collections: `admin.components` only.
     - `payload.config.ts`, `migrations/index.ts`, `e2e/tests/staff.spec.ts`, `docs/design/system.md`
     - `packages/ui/src/{index.ts,styles.css}`, `packages/core/package.json`, `pnpm-lock.yaml`
   - **QA fixes:**
     - The palettes and the `/admin` drawer now trap focus and close on Esc.
     - A long title no longer causes overflow at 375px.
     - Seven-digit money KPIs no longer clip.
     - Pager contrast now passes.
     - No Gravatar request.

4. **Open issues**
   - **Farjad decides (major):** with Persian as the default, most *field* labels on forms and list headers are still
     English. Examples: "Slug", "Kind", "Hero Image", "Instalments", "Idempotency Key". Payload generates them from
     field names. The options are:
     - add an fa label dictionary before release;
     - accept a mixed-language admin for now;
     - keep English for English browsers.
   - **Farjad decides (minor):** the "overdue instalments" KPI shows 0 while one instalment is past due. That
     instalment's last gateway attempt failed, so it is counted under "needs attention" instead. Recommendation: count
     overdue independently of attempts (`packages/core/src/staffGoals.ts` / `consoleData.openOrderInbox`).
   - **Farjad decides:** is the default (Gravatar-free) avatar acceptable? It is a one-line revert, but reverting
     brings back an external request.
   - **Payload-core axe findings:** on the `/admin` dashboard, list, form and account pages, the findings are
     react-select labels, icon-only buttons, the Lexical contenteditable name and doc-tab list roles. None come from
     our markup. `/admin/login` and all `/staff` desks have 0 violations.
   - **Payload core at 375px:** the document meta row and tabs scroll sideways, and their dates are Gregorian/English.
   - **Merge order:** PR #21 (E-028) is merged into this branch and must merge first. Whoever merges second re-creates
     their migration. Commit 1285002 does not typecheck alone (a181bf3 fixes it), so squash if every commit must build.
   - **Seed:** `instructor@demo.edvora.local` has no password. iba has no orders, enrolments or leads, so its KPIs are
     all zero.
   - **Cosmetic:** the sidebar label "سفارش‌ها و اقساط" opens the desk titled "مالی", so a palette search for "مالی"
     finds nothing.
