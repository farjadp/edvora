3. **Decisions made:**
   - Tests run against `next dev`, not `next start`: the seed uses Payload's dev schema push, and production boot
     applies migrations — mixing both on one DB is fragile. Cold compile is covered by 90s test timeouts.
   - Random fake phone per run so local re-runs against a non-reset DB don't collide (see QA-002).
   - `E2E_PORT` (default 3000) so the suite can run beside another dev server; `E2E_NO_SERVER=1` to reuse one.
   - Amounts asserted literally (12,000,000 − 20% → 40% down, rest in 3) to pin the instalment business rule end to end.
   - API checks use `localhost` (Payload REST isn't host-scoped), so Node DNS never needs `*.localhost`.
