All three: CSS-only motion, ease-out, off under `prefers-reduced-motion`; celebrations inline with `role="status"`;
quiz "not yet" has no red, no XP, primary action = review; gamification OFF is its own layout, not a hollowed one.

**Recommendation: A · Seal**, borrowing B's girih star as the certificate seal. Restraint reads as premium for
MBA/DBA executives, gold stays rare so milestones feel earned, it works on any tenant colour (checked blue, teal,
wine), and it is the lightest page. C only if Farjad wants a loud, youthful feel (could become a per-tenant preset).

3. **Decisions made:**
   - XP for outcomes, not screen time; each source pays once; 150 XP/day cap; quiz retakes pay 0 (flat 10 once when
     fail → pass). Numbers are starting values to tune after one cohort.
   - Streak = "weekly rhythm" (N learning days per Jalali week, default 2), auto freezes, weeks with no released
     content are neutral (needs E-026 drip data). No loss messages.
   - Leaderboard: tenant setting + per-student opt-in (default off), top 5 + own rank, initials/nickname, never bottom
     ranks, hidden until `[8]` students opt in.
   - Staff: advisor goal moves only when a follow-up has a recorded outcome; team gets one shared goal, no individual
     ranking; finance gets an inbox-zero counter.
   - Master switch + per-mechanic toggles per tenant; when off, progress/week view/certificate path stay.
   - Append-only events ledger as source of truth, derived totals recomputable; schema left to tech-lead.
   - Celebrations are inline, never modals; max 1 per page view, 3 per day; certificate finale is the only full page.
   - Preview built route-local only (scoped CSS under `data-e027-option`); no edits to `packages/ui`, `/dashboard`,
     `/learn` or `/staff` (E-022 and E-026 are working there). One new token proposed: `--milestone` (gold).
